# The security gates the agent must clear before it opens a pull request.
#
# One `uv tool install` spec per line. Each lands in its own virtual environment with
# only its command on PATH. That isolation is not tidiness: these tools pin their
# transitive dependencies hard -- semgrep pins `mcp` to an exact version the Claude
# Agent SDK cannot use -- so one shared environment is either unsatisfiable or a silent
# downgrade of something the agent needs. It also means a scanner upgrade can never
# break the agent's runtime.
#
# Versions are pinned because a finding count is only meaningful next to the scanner
# version that produced it.
#
# verify_image.py checks that every command scan_tools.py invokes actually answers, and
# the build fails if one does not. A scanner that is installed but not on PATH exits 127
# and its empty output parses as zero findings, which is how a repository passes a gate
# that never ran.
