# What the agent process itself imports. Nothing else belongs here.
#
# The security scanners are deliberately NOT in this file. They are command-line tools
# the agent shells out to, and their dependency graphs collide with the SDK's: semgrep
# 1.145.0 pins `mcp==1.16.0` while claude-agent-sdk needs `mcp>=1.23.0`, so a single
# environment holding both is unsatisfiable. See requirements-scanners.txt -- each
# scanner gets its own virtual environment, which also means a scanner upgrade can
# never break the agent's runtime.
#
# Resolved and hash-pinned into requirements.lock.txt, which is what the image installs:
#     uv pip compile requirements.txt --python-version 3.13 \
#         --python-platform aarch64-manylinux2014 --generate-hashes \
#         --no-header -o requirements.lock.txt
